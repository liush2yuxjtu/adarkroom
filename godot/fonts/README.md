# Fonts

Playable text uses **Sarasa Mono SC** (SIL OFL 1.1) for Chinese and Latin, replacing JetBrains Mono and Noto Sans SC.

| File | Role |
| --- | --- |
| `SarasaMonoSC-Regular-subset.otf` | Godot theme default `FontFile` |
| `../build/web/fonts/SarasaMonoSC-Regular-subset.woff2` | HTML `@font-face` 400 |
| `../build/web/fonts/SarasaMonoSC-Bold-subset.woff2` | HTML `@font-face` 700 |

Glyphs subset to the remake’s copy.
